# AIM Protocol

> Financial access for African farmers — built on Solana.

## What is AIM Protocol?

AIM Protocol is a decentralized microfinance platform connecting smallholder farmers in Sierra Leone and across Africa to DeFi financial services. Farmers can establish a verifiable on-chain identity, request simulated crop-backed microloans, and transact in stable digital currency, no bank account required.

Built for the Solana Frontier Hackathon 2026.

## The Problem

Sierra Leone's economy depends heavily on agriculture, with the majority of the population relying on farming for their livelihoods. Yet smallholder farmers remain almost entirely excluded from formal financial systems, not because the need isn't there, but because the infrastructure was never built for them.

## The Solution

AIM Protocol puts farmers on Solana:

1. Connect a Phantom wallet
2. Mint a verifiable on-chain Farmer ID
3. Request a simulated crop-backed microloan
4. Receive funds on Solana devnet
5. Verify transaction on Solana Explorer

## Tech Stack
